Questions

Which event type do I choose for an engagement?

Choose 'Other function' in the app and set the function name to Engagement Ceremony. All the same features work.

Can I send it on Viber or Messenger too?

Yes. The invitation is a normal link, so you can paste it into any app. WhatsApp sending is built in.

Can I use the same design for the wedding later?

Yes. Wedding designs come in matching families, so the engagement and wedding cards can look related.

How much does it cost?

One design and 5 personal guest links are free for every function. Plus is Rs. 990 per event for unlimited guests, a list of who is coming and no Aradhanawa name on the card. A custom design is Rs. 4,900.
