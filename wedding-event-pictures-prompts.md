# Wedding event pictures: Church / Poruwa / Reception (image prompts)

Hama wedding card ekakama dan **Church ceremony, Poruwa ceremony, Reception** kiyala kotas 3k thiyenawa.
Ekin ekata wenama date, time, venue thiyenawa. Hama kotasakatama pahe couple picture ekak (square) one.

Picture tika ena kan card eke e kotuwe **gold line emblem** ekak penawa (church, poruwa, cups). Ewa wada karanawa,
picture ena gaman ewa automatically maru wenawa.

Video naha. Me okkoma **images** witharai.

---

## Karanna one de (simple steps)

1. **ChatGPT** (ho Gemini) open karanna. Hama design ekakatama **aluth chat ekak** ganna.
2. Pahala design eke **"Couple"** text eka mulinma paste karanna, ita passe **1. Church** prompt eka paste karala generate karanna.
3. Eka chat ekema **2. Poruwa** prompt eka paste karanna, passe **3. Reception**. (Eka chat eke karama couple ge muhuna 3 ema samaanai.)
4. Picture eka hondai nam download karanna. Size eka **square (1:1)**, 1024 x 1024 hondai.
5. Picture 3ma **me thread ekata upload karanna**, design eke namai, kotasa (church / poruwa / reception) kiyala.
   Mama ewa `720 x 720 WebP` karala hari filename eken site ekata danawa. Oyata rename karanna one naha.

Hama prompt ekakatama anthimata danna: `no text, no letters, no watermark, no logos, no frame, no border`.
(Card eke gold frame eka code eken danawa, e nisa picture eke frame ekak epa.)

Tip: Muhuna lassana naththam "make the faces softer and more natural" kiyala aye illanna.
Design ekakata picture 3 karanna kalin dan **Lotus Mandala** eka witharak karath athi: anith designs walatath e picture tika penawa, passe ewayeka ewaye picture ena kan.
